## Server pieces you must configure
- `api/welcome.js`: set `RESEND_API_KEY`, `WELCOME_FROM`, `APP_URL` in Vercel → Settings → Environment Variables. Without them the app reports "Not sent" honestly.
- `version.json`: bump `version` when you deploy a new build. The app polls it (no-store) and offers "Update now", which clears the cache and reloads in place — no uninstall.
- `sw.js` VERSION is `nancyflix-v6.0.0`; bump it together with `version.json`.

## Legal limits
Channels are official free-to-air YouTube live feeds embedded in the app. Fixtures and tables come from TheSportsDB; rights-protected matches are never re-streamed. Downloads save poster artwork only.
