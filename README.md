## 🎬 About NANCYFLIX

A modern entertainment platform bringing **Live TV, Football, Kids Entertainment and Audio Experiences** together in one place.

<details>
<summary>✨ Explore the features</summary>

- 📺 39 Free-to-air TV channels.
- ⚽ Football fixtures, scores and match posters.
- 🧒 Dedicated Kids Corner.
- 🎵 8 Focus and 7 Sleep recordings.
- 📲 Social match sharing with automatic previews.
- 🔐 Email authentication and guest access.
- 📱 Responsive mobile experience.
- 📡 Offline support and saved content.

</details>

## 🛠️ Deployment

1. Upload the complete project files.
2. Configure environment variables using `docs/CONFIGURATION.md`.
3. Run the Supabase SQL files.
4. Deploy through Vercel.
5. Test guest, member and owner access.

📖 Read the deployment guide: `docs/DEPLOYMENT.md`

🔐 Security guide: `docs/SECURITY.md`

## ⚠️ Important

- Always deploy the complete project, including `api/`, `audio/`, `icons/` and `docs/`.
- Confirm `version.json` displays `8.7.0`.
- Free-tier provider limits and channel availability may change.
- See `docs/TESTING_REPORT.md` for testing limitations.
